Ratatosk is a [Python][python] package for validated electrochemical data-processing, analysis and integrity tool for
battery research. It is developed by Dr Nik Reeves-McLaren of the [Advanced Characterisation of Energy Materials][acem]
in collaboration with the [Research Software Engineering Team][rse] at the [University of Sheffield][tuos].

# Get Started

If you are looking to use Ratatosk there are instructions on how to [install](install.md) the package and [use
it](usage.md). Contributions are welcome and we have some hopefully useful information on how to go about this in our
[contributing](contributing.md) page.

## Get in touch

You can contact the developers via email at [ratatosk@sheffield.ac.uk](mailto:ratatosk@sheffield.ac.uk).
