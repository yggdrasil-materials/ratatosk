Ratatosk is a [Python][python] package for validated electrochemical
data-processing, analysis and integrity tool for battery research. It is
developed by Dr Nik Reeves-McLaren of the [Advanced Characterisation of Energy
Materials][acem] in collaboration with the [Research Software Engineering
Team][rse] at the [University of Sheffield][tuos].

# Get Started

If you are looking to use Ratatosk there are instructions on how to
[install](install.md) the package as well as guidelines on
[contributing](contributing.md)
