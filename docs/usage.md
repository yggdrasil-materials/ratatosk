# Usage

Once you have [installed](install.md) `ratatosk` in a virtual environment you
are ready to start using it. There are two methods, the Command Line Interface
(CLI) or via Notebooks (either [Jupyter][jupyter] or [Marimo][marimo])

## Notebooks

**NB** Whilst you can use either [Jupyter][jupyter] or [Marimo][marimo]
notebooks it is recommended to use the later as they solve one of the major
problems of [cell dependency][marimo_reactive] and the problems that arise when
these are run out of order.

[jupyter]: https://jupyter.org/
[marimo]: https://marimo.io
[marimo_reactive]: https://docs.marimo.io/guides/reactivity/
